# Agente operativo durable con MCP

**Fase 4 · Semanas 13–16**

## Qué hay que entregar

- ☐ 5+ herramientas reales, al menos una de escritura con confirmación humana
- ☐ Ejecución durable con checkpointing: sobrevive a matar el proceso a mitad
- ☐ Presupuesto por ejecución (tokens, pasos, coste) con corte duro
- ☐ Tool loadout dinámico, con tokens ahorrados medidos
- ☐ Trazas completas: qué pensó, qué llamó, qué recibió, cuánto costó
- ☐ Servidor MCP exponiendo 2+ de esas herramientas
- ☐ 3+ escenarios de prompt injection indirecta que debe resistir
- ☐ Construido en TypeScript. Opcional: segunda versión en Rails + ADR comparativo
